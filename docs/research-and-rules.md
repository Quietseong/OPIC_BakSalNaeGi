# 자료 분석 및 구현 규칙

확인일: 2026-11-04. ego-browser를 통해 직접 열람했다.

## 공식 규칙

출처: [한국 OPIc 공식 시험소개](https://www.opic.or.kr/opics/servlet/controller.opic.site.about.AboutServlet?p_process=move-introduce-opic)

| 확인된 규칙 | 앱 구현 결정 |
| --- | --- |
| 12~15문항 | 세트 데이터에 문항 수를 두고 15문항으로 고정하지 않음 |
| 본시험 40분, OT 포함 약 60분 | 실전 모드 본시험 타이머는 40분. 장비 점검과 사전 설정은 분리 |
| Background Survey → Self Assessment → 장비 점검 → Sample Question | 실전 설정 흐름에 순서 반영. 연습에서는 간소화 가능 |
| 1차 약 7문항 → 난이도 재조정 → 2차 약 5~8문항 | 세트에 분기 지점과 쉬운·비슷한·어려운 경로를 명시 |
| 각 세션 질문 청취 2회 | 실전 모드 청취 횟수 관리. 반복 버튼의 활성 시점은 추가 확인 |
| 문항별 답변시간 제한 없음 | 90초·120초는 선택적 연습 목표로만 사용. 실전에서는 문항별 자동 종료 금지 |
| 전체 답변에 대한 Holistic Evaluation | AI는 문항별 코칭과 세션 전체 피드백을 구분 |
| Function, Accuracy, Content/Context, Text Type | 피드백 데이터에 해당 관점과 발화 근거를 연결 |

공식 페이지는 현재 영어에 Machine Scoring과 Human QA를 안내한다. 학습 글의 과거 설명을 근거로 ‘공식 시험은 반드시 사람만 채점한다’고 제품에 표시하지 않는다. 자체 AI 평가는 공식 채점과 동등한 것으로 설명하지 않는다.

미확정: 첫 질문의 채점 여부, 재청취 허용 구간, 녹음 시작·종료 시점, 이전 문항 이동, 시간 만료 시 저장 절차, 국내 자기평가 단계와 분기별 실제 출제 알고리즘. 공식 튜토리얼 확인 전까지 앱 자체 연습 규칙과 구분한다.

## 학습 글 분석

출처: [ChatGPT로 IH 도전하기 - 1](https://gall.dcinside.com/mgallery/board/view/?id=opic&no=48801), 게시일 2026-05-12.

이 글은 IH 취득 후기가 아니라 도전 기록이다. 포함된 보고서와 프롬프트의 효과가 검증되었다고 해석하지 않는다. 글 작성자의 영어 점수·학습 여건·IH 목표를 앱 사용자의 정보로 간주하지 않는다.

참고할 학습 흐름:

- 개인의 실제 경험을 이야기 소재로 준비하고 여러 질문에 맞게 다시 구성한다.
- 묘사, 루틴, 경험, 롤플레이, 비교, 이슈 유형을 구분해 연습한다.
- 녹음 또는 전사문에서 질문 적합성, 구성, 시제, 구체성, 반복 표현을 점검한다.
- 수정한 뒤 같은 질문에 다시 답하고 이전 녹음과 비교한다.
- 약한 유형에 대해 짧은 훈련 세트를 반복한다.

제품 반영:

1. MVP 복기에 자가 메모와 재녹음 경로를 둔다. 원본을 덮어쓰지 않고 시도별 기록을 연결한다.
2. 후속 기능으로 주제별 이야기 메모와 약점 태그를 제공한다.
3. AI 피드백은 질문 요구 충족 여부, 발화 근거, 우선 개선점, 쉬운 표현 제안, 재답변 과제로 구성한다.
4. 90초 묘사·120초 경험 답변 등의 수치는 연습 프리셋이며 공식 등급 요건으로 표시하지 않는다.
5. 연습 중 즉시 코칭과 모의시험 종료 후 코칭을 구분한다.

## 영상 확인 범위

출처: [여우오픽 모의고사 난이도 5~6 #16](https://www.youtube.com/watch?v=tDd601t-sbY).

영상 제목, 채널, 재생 길이 2084초(34분 44초)를 확인했다. 자막은 없다. 2026-11-04 재조사에서 설명란 전문과 YouTube storyboard(10초 간격 썸네일)를 확인했다.

- 문항 수: 15문항. 설명란에 설문 선택값과 15문항 텍스트가 있다.
- 구성: 1번 자기소개, 2~4·5~7·8~10번 주제별 3문항 묶음(묘사 → 루틴·변화 → 경험), 11~13번 롤플레이 묶음(질문하기 → 문제 해결 → 관련 경험), 14~15번 비교·이슈.
- 화면: 시험 화면을 흉내 낸 아바타, 문항 번호 격자, 재생 버튼, Next 버튼. 문항마다 약 2:00 카운트다운이 표시되고, 마지막에 종료 화면이 나온다. 시간은 10초 간격 썸네일로 읽은 값이다.
- 판단: 2분 카운트다운은 영상의 연습 장치이며, 공식 규칙(문항별 답변시간 제한 없음)과 다르다. 앱에서는 선택형 연습 프리셋으로만 둔다. 영상의 문항 텍스트는 앱 콘텐츠로 복사하지 않고, 같은 구조의 자체 문항을 쓴다.

## 2026-11-04 검증 추가 결과

공식 튜토리얼: 공식 FAQ "튜토리얼과 실제시험이 동일한가요?"에 따르면 Sample Test는 평가 진행요령 체험용이며, Background Survey 항목만 실제와 다를 수 있다. 튜토리얼 첫 화면 다음의 ACTFL 윤리 규정 동의 화면에서 진행을 멈췄다. 따라서 다시 듣기 활성 시점, 녹음 시작 시점, 이전 문항 이동은 여전히 미확인이다.

윤리 규정에서 확인한 내용:

- 암기했거나 반복 연습한 발화만 계속하면 Novice로 간주된다. 다른 응시자의 콘텐츠를 따라하거나 외워 쓰는 것은 부정행위다.
- 시험 문항은 ACTFL 저작물이며 공유가 금지된다.
- 앱 반영: 재답변과 메모 기능은 대본 암기가 아니라 상황에 맞춰 바꿔 말하는 연습으로 안내한다. 문항은 자체 작성한다.

브라우저 기술 검증(ego Chromium, localhost):

| 확인 | 결과 | 앱 반영 |
| --- | --- | --- |
| MediaRecorder 형식 | `audio/webm;codecs=opus`, `audio/webm`, `audio/mp4` 지원. ogg와 wav는 미지원 | 실행 시 지원 형식을 선택 |
| 사용자 동작 없는 녹음 | AudioContext가 시작되지 않아 0바이트 녹음 | 녹음과 질문 재생은 버튼 클릭으로 시작 |
| 클릭 후 녹음 → IndexedDB → 새로고침 | 2초 녹음 32,135바이트, 새로고침 후 같은 크기, 1.98초로 디코딩 | 저장 방식 확정 |
| `<audio>` 길이 | WebM 녹음은 `Infinity` | 녹음 길이를 앱이 직접 측정해 저장 |
| `navigator.storage.persisted()` | false | 시작할 때 `storage.persist()` 요청, 내보내기 제공 |
| 실제 마이크 | 미검증(권한 상태 prompt) | 수동 확인 필요 |

## 우선순위 확정

P0: 한 문항 재생·녹음·영구 저장·다시 듣기, 권한 및 저장 오류 처리.

P1: 고정 세트 전체 진행, 복기 및 재답변 이력, 내보내기·삭제, 실제 장치 검증.

P2: 실전 모드와 중간 난이도 분기. 공식 페이지로 확인한 규칙(청취 2회, 문항별 시간제한 없음, 40분, 1차 약 7문항 뒤 쉬운·비슷한·어려운 선택)만 공식 규칙으로 표시한다. 다시 듣기 활성 시점, 이전 문항 이동 금지, 40분 만료 시 처리는 앱 자체 규칙으로 표시한다. 설문 기반 세트 선택은 후속으로 미룬다.

P3: 음성 전사·AI 피드백, 이야기 소재 관리, 약점 훈련. 공식 출제 알고리즘의 재현이나 등급 보장은 범위에 포함하지 않는다.

개발 착수 기준: P0는 현재 명세로 시작 가능하다. P2의 실전 재현 완료 판정은 미확정 규칙 확인 후 진행한다.
