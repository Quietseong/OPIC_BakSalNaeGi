## 현재 상태

사용자는 ego-browser 자료와 여우오픽 모의고사를 참고하는 OPIc 연습 앱을 원하며, 작업 정리 및 개발계획부터 요청했다. 계획 문서 작성 완료. 앱 코드, 패키지, 빌드 도구, 테스트는 아직 없다. 이 인계 자체는 추가 구현 승인으로 간주하지 말고, 사용자의 해당 세션 지시에 따라 진행한다.

자료: 사용자 지정 YouTube 영상 `https://www.youtube.com/watch?v=tDd601t-sbY`, 학습 글 `https://gall.dcinside.com/mgallery/board/view/?id=opic&no=48801`, 한국 OPIc 공식 시험소개. 상세 출처와 검증 상태는 research-and-rules.md 참고.

## 합의 전 제안 사항

React + TypeScript + Vite, MediaRecorder 녹음, IndexedDB 로컬 저장. 개인용 PC 웹 앱을 우선하는 제안이며 사용자 확정 사항은 아니다. 서버·로그인·결제·AI 호출은 첫 구현에 필요하지 않다.

## 구현을 요청받으면 시작할 작업

P0: 자체 작성한 한 질문의 음성 재생 → 답변 녹음 → IndexedDB 저장 → 새로고침 후 다시 듣기. 권한 거부와 저장 실패를 처리한다. 이후 전체 세트 진행, 복기와 재답변 이력, 내보내기·삭제로 확장한다. 녹음 상태 전이와 저장 실패를 의미 있게 테스트한다.

공식 안내로 확인: 12~15문항, 본시험 40분, 질문 청취 2회, 문항별 답변시간 제한 없음, 중간 난이도 재조정. 90초·120초는 연습 목표일 뿐 공식 제한시간이 아니다. 세부 재청취·문항 이동·녹음 타이밍과 영상 타임라인은 미확인이다. 실전 모드 구현 전 검증한다.

학습 글의 IH 목표와 작성자 영어 점수는 사용자 프로필이 아니다. AI 평가는 공식 성적을 보장하지 않는다. 앱 콘텐츠는 자체 작성 또는 사용 권한이 있는 자료로 만든다. API 키를 브라우저에 넣지 않는다.

## 작업 규칙

기존 파일과 적용되는 AGENTS.md를 먼저 확인한다. 사용자 홈 전체를 프로젝트로 다루지 말고 이 디렉터리에서 작업한다. src/, tests/, assets/, docs/ 구조를 사용하고 도구를 도입하면 실행·테스트 명령을 문서화한다. 현재 세션이 만들거나 수정한 내용을 먼저 파악하고 덮어쓰지 않는다.

브라우저가 필요하면 사용자가 지정한 ego-browser 스킬을 읽고 `ego-browser skill` 출력에 따른다. 이전 조사 TaskSpace 5는 종료되었으므로 그대로 재개하지 않는다.
