# OPIc 말하기 연습

질문을 듣고 영어 답변을 녹음한 뒤, 문항별로 다시 듣고 메모하는 개인용 로컬 웹 앱입니다. 서버, 로그인, 외부 전송이 없습니다. 녹음은 브라우저의 IndexedDB에만 저장됩니다.

## 실행

Node 20.18 이상과 Windows 영어 음성(기본 설치된 Microsoft Zira)이 필요합니다.

```bash
npm install
npm run audio   # 질문 음성 WAV 생성 (public/audio, git 제외). 이미 있으면 건너뜀. 다시 만들려면 -- --force
npm run dev     # http://localhost:5173 을 Chrome 또는 Edge로 연다
```

질문 음성은 생성된 WAV, 브라우저 음성 합성, 질문 텍스트 순서로 시도합니다. 마이크는 localhost에서만 동작합니다.

## 모드

| 모드 | 동작 |
| --- | --- |
| 연습 | 자기 수준에 따라 12·14·15문항, 질문 텍스트 표시, 다시 듣기 제한 없음, 다시 녹음 가능, 90초·120초 목표 표시(자동 종료 없음) |
| 실전 | 질문 텍스트 숨김, 질문 청취 2회, 전체 40분, 7번 뒤 쉬운·비슷한·어려운 선택(12·14·15문항) |

## 훈련 기능

모의고사는 실력을 재는 도구라서, 실력을 키우는 훈련을 따로 둡니다. 모두 서버나 AI 없이 동작합니다.

| 기능 | 위치 | 동작 |
| --- | --- | --- |
| 3번 줄여 말하기 | 홈 → 훈련 | 같은 질문에 90초 → 70초 → 50초 제한으로 세 번 답한다(4/3/2 기법). 제한 시간에 녹음이 자동으로 멈추고, 끝나면 세 녹음을 비교한다 |
| 답변 뼈대와 덩어리 표현 | 연습 모드, 훈련 | 질문 유형(묘사, 루틴, 변화, 경험, 롤플레이, 비교, 이슈)별 답변 순서와 짧은 표현. 실전 모드에서는 숨긴다 |
| 받아쓰기와 고쳐 말하기 | 복기, 훈련 결과 | 녹음마다 "내가 실제로 한 말"과 "고친 문장"을 적는다. 다시 답변할 때 마지막으로 고친 문장이 함께 보인다 |
| 간격 반복 | 복기, 훈련 결과, 홈 | 막힌 질문은 다음 날, 잘 된 질문은 3·7·14·30일 뒤 "오늘 복습할 질문"에 다시 나온다 |

공식 OPIc 윤리 규정상 외운 답변만 반복하면 Novice로 평가됩니다. 덩어리 표현은 짧게 익히고, 답변 내용은 매번 내 경험으로 채우세요.

## 문항 조합

문항은 `src/domain/question-pool-data.ts`의 풀(주제 12개, 롤플레이 8개, 고난도 8개, 모두 139문항)에서 시작할 때마다 새로 조합됩니다. 조합 규칙은 앱 자체 규칙입니다.

- 1차 7문항은 자기소개 1개와, 설문에서 고른 주제 2개의 묶음(묘사 → 루틴 또는 변화 → 경험)입니다. 자기 수준이 1~2단계면 루틴, 3단계 이상이면 변화 문항을 씁니다.
- 2차는 고르지 않은 주제의 돌발 묶음, 롤플레이, 고난도 문항으로 구성합니다. 쉬운 질문은 5문항, 비슷한 질문은 7문항, 어려운 질문은 8문항입니다.
- 이전 버전의 고정 세트 A로 녹음한 기록도 복기 화면에서 그대로 열립니다.

공식 규칙과 앱 자체 규칙의 구분은 `docs/research-and-rules.md`에 있습니다.

## 테스트

```bash
npm test           # 상태 머신, 세션 흐름, IndexedDB 저장 (Vitest + fake-indexeddb)
npm run test:e2e   # Chromium 가짜 마이크로 전체 흐름 (Playwright). 처음 한 번 npx playwright install chromium
npm run build      # 타입 검사 + 프로덕션 빌드
```

## 구조

- `src/domain`에는 문항 세트, 세션 진행 규칙, 문항별 상태 머신이 있습니다. React에 의존하지 않습니다.
- `src/storage/db.ts`는 IndexedDB 저장소입니다. 답변 메타데이터와 녹음은 한 트랜잭션으로 저장됩니다.
- `src/media`는 마이크 녹음과 질문 재생을 맡습니다.
- `src/ui`는 React 화면입니다.
- `docs/decisions.tsv`는 구현 중 내린 결정과 근거를 기록한 로그입니다.

## 알려진 제한

- 실전 모드의 40분은 시작 시각 기준이라, 앱을 닫아 둔 동안에도 줄어듭니다.
- 녹음을 저장하지 않은 문항을 새로고침 후 이어서 하면 청취 횟수가 다시 2회로 돌아갑니다.
- 다시 듣기 활성 시점, 이전 문항 이동 금지, 40분 만료 시 저장 후 종료는 공식 튜토리얼로 확인하지 못한 앱 자체 규칙입니다.
- 자동 테스트는 Chromium 가짜 마이크로 실행합니다. 실제 마이크(권한 거부, 장치 분리, 무음)는 직접 확인해야 합니다.
